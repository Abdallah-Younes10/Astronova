🌌 Astronova – Interactive Space Exploration Platform
Astronova is an interactive web platform designed to make space exploration accessible, visual, and intelligent.
The project combines real NASA data, 3D visualizations, and AI-powered explanations to deliver a modern educational experience about the universe.
🚀 Key Features
🔭 1. 3D Solar System Visualization
Interactive 3D models built with Three.js
Realistic motion of planets around the sun
Click any planet to view detailed information, facts, and images
🛰 2. NASA Data Hub
Powered by NASA Open APIs:
Astronomy Picture of the Day (APOD)
James Webb Space Telescope images
Latest space missions and events
Earth satellite imagery
🌙 3. Space Labs (Interactive Simulations)
Calculate your weight on any planet
Visualize gravity differences
Explore comet trajectories
Simple rocket-building simulation
📱 4. AR Planet Viewer (Optional)
View planets using Augmented Reality
Web-based AR using AR.js / WebXR
🧰 Tech Stack
Frontend: HTML / CSS / JavaScript
Backend: Laravel
Database: MySQL 
🎯 Purpose
Astronova aims to make astronomy fun, modern, and interactive — combining education with cutting-edge web technologies to inspire curiosity about the universe.
📌 Project Goals
Visualize space in an interactive and understandable way
Provide real NASA data in a user-friendly platform
Use AI to explain complex concepts
Encourage users to explore and learn about the cosmos
